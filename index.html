⚡ ESP32 Studio

Flash firmware and watch serial output straight from your browser.

Web Serial isn’t available here. Open this page in Chrome or Edge on a desktop computer.

1 · Flash firmware

Merged firmware files (like Bruce) go at 0x0. App-only files usually go at 0x10000. MicroPython goes at 0x1000 on a classic ESP32, or 0x0 on S3/C3. Hold BOOT while connecting if the board isn’t detected.

2 · Serial monitor









3 · Write code (MicroPython)


One-time setup: flash the MicroPython firmware in step 1 (download it from micropython.org/download for your board). Then connect the serial monitor in step 2 and write code here. No other software needed.







Run tries the code now. Save as main.py keeps it on the board and starts it every time the board powers up.
